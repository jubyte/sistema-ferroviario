# MANUAL DO USUÁRIO
### Ferrorama Mocking Rail

---

## 1. INTRODUÇÃO

O Sistema de Monitoramento Ferroviário Inteligente foi desenvolvido para a Ferrorama Mocking Rail com o objetivo de auxiliar no acompanhamento das operações ferroviárias. O sistema utiliza informações provenientes de sensores para apresentar dados como velocidade, localização, consumo de energia e possíveis falhas.

Este manual apresenta as principais funcionalidades do sistema e orienta o usuário sobre sua utilização, desde o acesso à aplicação até o gerenciamento das informações disponíveis.

---

## VISÃO GERAL

O sistema é uma aplicação web desenvolvida para centralizar informações relacionadas à operação ferroviária. Por meio dele, o usuário pode acessar diferentes áreas da aplicação, realizar seu login e consultar ou gerenciar informações de acordo com as funcionalidades disponíveis.

Entre as principais áreas do sistema estão:

* Página institucional;
* Cadastro e login de usuários;
* Menu de informações;
* Gerenciamento de usuários;
* Gerenciamento de sensores;
* Gerenciamento de trens;
* Rotas.

Algumas dessas funcionalidades podem estar em desenvolvimento durante a utilização do sistema.

---

## ACESSO AO SISTEMA

Para acessar o sistema, o usuário deve abrir a aplicação pelo navegador e acessar a página inicial.

Na página inicial, estão disponíveis as informações institucionais da Ferrorama, além do acesso à área de login.

### Login

Na tela de login, o usuário deve informar:

* E-mail;
* Senha.

Após preencher os campos, deve selecionar a opção **ENTRAR**.

Caso os dados estejam corretos, o usuário será direcionado para a área principal do sistema.

Se houver algum problema com os dados informados, uma mensagem será apresentada na tela para orientar o usuário.

### Cadastro

Caso ainda não possua uma conta, o usuário pode selecionar a opção **“Não tem uma conta? Cadastre-se”**.

A tela será alterada para o modo de cadastro, permitindo o preenchimento dos dados necessários.

Após realizar o cadastro, o usuário poderá retornar à tela de login para acessar o sistema.

---

## NAVEGAÇÃO PELO SISTEMA

Após realizar o acesso, o usuário encontrará um menu lateral que permite navegar pelas principais áreas da aplicação.

Entre as opções disponíveis estão:

* **Menu:** apresenta as principais informações e indicadores do sistema, permitindo uma visão geral da operação ferroviária.
* **Usuários:** permite realizar o gerenciamento dos usuários cadastrados no sistema, incluindo suas informações e acessos.
* **Sensores:** permite realizar o gerenciamento dos sensores utilizados para coletar informações da operação ferroviária.
* **Trens:** destinada ao cadastro e gerenciamento das informações dos trens utilizados pela empresa.
* **Rotas:** destinada ao gerenciamento das rotas ferroviárias utilizadas pelo sistema.
* **Sair:** encerra o acesso do usuário à área interna do sistema.

As telas estão em desenvolvimento. Suas funcionalidades serão implementadas e atualizadas conforme o desenvolvimento do sistema.

O usuário deve utilizar o menu lateral para acessar a funcionalidade desejada.

---

## DICAS E BOAS PRÁTICAS

Para utilizar o sistema corretamente, recomenda-se:

* Preencher todos os campos obrigatórios antes de realizar um cadastro;
* Conferir as informações antes de salvar ou alterar um registro;
* Utilizar dados corretos e atualizados;
* Utilizar o campo de busca para localizar registros com mais facilidade;
* Não compartilhar informações de acesso com outras pessoas;
* Encerrar o acesso ao sistema utilizando a opção **Sair**;
* Em caso de erro, verificar as informações preenchidas antes de tentar novamente.

---

## SOLUÇÃO DE PROBLEMAS

### Não consigo acessar o sistema

Verifique se o e-mail e a senha foram preenchidos corretamente. Caso o problema continue, confira se o cadastro foi realizado anteriormente.

### O sistema informa que existem campos obrigatórios vazios

Verifique todos os campos do formulário e preencha as informações solicitadas antes de realizar o cadastro.

### Não encontro um usuário ou sensor

Utilize o campo de busca e confira se o nome ou identificador foi digitado corretamente.

### Não consigo realizar uma alteração

Verifique se o registro selecionado existe e se as informações preenchidas são válidas.

### Uma funcionalidade não está disponível

Algumas funcionalidades do sistema ainda podem estar em desenvolvimento. Nesse caso, a opção poderá estar disponível apenas em versões futuras da aplicação.

### O sistema apresenta um erro inesperado

Confira os dados preenchidos e tente realizar a operação novamente. Se o problema persistir, entre em contato com a equipe responsável pelo sistema.

---

## SUPORTE

Em caso de dúvidas, dificuldades de acesso ou problemas durante a utilização do sistema, o usuário deve entrar em contato com a equipe responsável pelo desenvolvimento do Sistema Mocking Rail.

O suporte é destinado a auxiliar na identificação de problemas relacionados ao funcionamento da aplicação e ao uso de suas funcionalidades.

Ao solicitar suporte, recomenda-se informar:

* Nome do usuário;
* Funcionalidade em que ocorreu o problema;
* Descrição do problema;
* Ação realizada antes do erro;
* Mensagem apresentada pelo sistema, quando houver.

Os canais de suporte definidos pela equipe responsável pelo projeto devem ser utilizados para registrar dúvidas, problemas e solicitações relacionadas ao sistema.

---

## CONCLUSÃO

Este manual apresenta as orientações básicas para utilização da aplicação e pode ser atualizado conforme novas funcionalidades forem desenvolvidas e incorporadas ao sistema.
